# notebooks

Initial exploration and development notebooks, numbered to follow the research narrative.

They illustrate the thinking process, but all reusable logic is contained in the package, and all results and figures shown in the report are generated by scripts. 

The code within the notebooks is now outdated, as the package and scripts have developed further, but the notebooks are kept as an illustration of the development pipeline. 

| Notebook | Topic |
|---|---|
| `01_tomosipo_fundamentals` | Exploration of the Tomosipo package. |
| `02_ct_physics_exploration` | Exploring sparse-view CT, the artefacts produced, and the issues that arise. |
| `03_dataset_visualisation` | Visualising LIDC slices and HU windows. |
| `04_lion_exploration` | Investigating LION operators and conventions. |
| `05_pnp_admm_exploration` | Developing FBP, TV, DRUNet, PnP-ADMM convergence. |
| `06_tfpnp_paper_analysis` | Understanding of Wei et al. (2022). |
| `07_policy_network_dev` | Development of the policy architecture. |
| `08_admm_environment_dev` | Differentiable ADMM environment. |
| `09_training_pipeline` | RL training loop. |
| `10_experiments_and_results` | Main results and figures for the notebook run. |
| `11_additional_baselines` | Additions of FBPConvNet. |
| `12_ct_denoiser_development` | Extension of CT-domain DRUNet. |
